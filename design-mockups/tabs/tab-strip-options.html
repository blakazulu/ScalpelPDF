Tab bar: three options

Each option is live. Click a tab to switch, hover it to close, middle-click to close, drag to reorder, right-click for the tab menu. The dot marks a document with unsaved changes; closing it asks first.

Theme
The window is drawn at 1180 px and scaled to fit. Colors, type and ribbon come from the Clinical theme files.

A - Tabs in the title bar

  • Most like Chrome and Edge. The open tab flows into the ribbon, so the ribbon reads as acting on that document.
  • Costs no height: the file name label in the title bar is replaced by the tabs.
  • Less room to drag the window; empty title-bar space and the brand area stay draggable.

B - Tab row under the ribbon

  • The open tab joins the page area below it, like Word or VS Code editor tabs.
  • Title bar stays as it is today; adds a 36 px row.
  • Two tab rows (View / Edit / Pages / Sign and the documents) sit close together; the different shapes keep them apart.

C - Compact chips

  • The closest to today's tab strip, made complete: dirty dot, close on hover, menu, reorder.
  • Lightest look; reads more like filters than documents.
  • Adds a 36 px row; chips do not shrink, so many files scroll sooner.

Shortcut changes (Ctrl+1..9 go to tabs)

Ctrl+1 .. Ctrl+8Go to tab 1 to 8
Ctrl+9Go to the last tab
Ctrl+T / Ctrl+WNew blank tab / close tab
Ctrl+Tab, Ctrl+PgDnNext tab (Shift / PgUp for previous)
Ctrl+0Actual size (unchanged)
Ctrl+Shift+2Fit width (was Ctrl+2)
Ctrl+Shift+3Fit page (was Ctrl+3)
